## 2. Probe — zero external requests (the sprint's hard constraint)

```
$ grep -rnoE '(url\(["'\'']?https?://|@import[^;]*https?://|(src|href)=["'\'']https?://|fetch\(["'\''`]https?://)' dist/
(exit 1 — no match)

$ ls dist/assets/ | grep -iE 'woff|ttf|otf'     → none
```

After the build, `dist/` contains no request-shaped external reference and no font file. The three absolute
URLs that *do* appear in the bundle are strings, not requests — `www.w3.org` (namespaces React writes into
the DOM), `react.dev` (inside React's production error messages), `tailwindcss.com` (a licence banner
comment) — and a headless Chromium run with every non-loopback host mapped to `NOTFOUND` requests **six
URLs: three from the page** (`/`, the two `/assets/…` files) **and three browser-level attempts** to
`clients2.google.com`, `accounts.google.com` and `www.google.com` that `--disable-background-networking`
does not suppress. Attribution is by control, not by assumption: `about:blank` under the same flags emits
exactly those same three Google URLs, the page renders byte-identically with that traffic blocked, and the
count of browser-level attempts varies between runs while the page's own three never do. `index.html`
carries `<link rel="icon" href="data:," />`, so the browser's `/favicon.ico` probe is gone — before that
line the run showed seven URLs, four of them same-origin.

**This is the story's most useful output.** The colour pipeline E2-S4 builds cannot be tested in jsdom as

## 4a. Probe — Tailwind v4 scans documentation (found by the E2-S1 review)

```
$ grep -o '\.static{[^}]*}' dist/assets/*.css
.static{position:static}

$ grep -rnw static frontend/ --exclude-dir=node_modules --exclude-dir=dist
frontend/README.md:17:| `npm run build` | `tsc -b && vite build` → static bundle in `dist/` …

$ sed -i 's/static bundle/compiled bundle/' frontend/README.md && npx vite build && grep -c '\.static{' dist/assets/*.css
0                       # restored: 1
```

The only occurrence of the word "static" under `frontend/` outside `node_modules/` is that sentence in the
README, and replacing it removes the utility from the stylesheet — so v4's automatic source detection is
scanning Markdown prose, not just components. Documentation therefore ships utilities, and a doc-only edit
can change the CSS bytes and its content hash. Scoping is E2-S3's (it is in that story's acceptance
criteria); ADR-014 now names the default scope and this evidence, and `frontend/README.md` carries the
warning.
