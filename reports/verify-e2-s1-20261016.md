## 2. Probe — zero external requests (the sprint's hard constraint)

```
$ grep -rnoE '(url\(["'\'']?https?://|@import[^;]*https?://|(src|href)=["'\'']https?://|fetch\(["'\''`]https?://)' dist/
(exit 1 — no match)

$ ls dist/assets/ | grep -iE 'woff|ttf|otf'     → none
```

After the build, `dist/` contains no request-shaped external reference and no font file. The three absolute
URLs that *do* appear in the bundle are strings, not requests — `www.w3.org` (namespaces React writes into the
DOM), `react.dev` (inside React's production error messages), `tailwindcss.com` (a licence banner comment) —
and a headless Chromium run with every non-loopback host mapped to `NOTFOUND` renders the page byte-identically
while requesting only `/`, the two `/assets/…` files and `/favicon.ico`. A control run of `about:blank` under
the same flags shows the same browser-level service traffic, so it is not the page.
