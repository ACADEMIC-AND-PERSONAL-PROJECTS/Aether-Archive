# Sprint plans

One file per sprint: `sprintNN.md` (two-digit number, e.g. `sprint01.md`), created by `/start-sprint`
and kept truthful during the sprint. The retrospective lives one level up in `retrospectives/sprintNN.md`.

Sprint docs are **append-friendly**: the `Notes / decisions during the sprint` section takes raw entries
as the sprint progresses and becomes the main input for the retrospective.

See `docs/scrum/SPRINT-PLAYBOOK.md` for the cadence and the schedule table.
